# 夏期講習シフト確認フォーム（戸田校）

先生が自分の名前を選ぶと **担当コマだけ** が表示され、各コマを
◯（OK）／△（要相談）／✕（NG）で確定して送信すると、
回答が **Googleスプレッドシートに自動で1行ずつ溜まる** Webフォームです。

先生のコピペ返信も、こちらでの手集計も不要です。

- **公開URL（先生用フォーム）**: https://hirokonishi4309-prog.github.io/summer-shift-toda/
- **対象**: 2026 夏期講習・戸田校
- **回答の保管先**: Googleスプレッドシート「夏期講習シフト回答」

---

## 仕組み（3つの無料サービスの組み合わせ）

| 役割 | 使うもの | 何をしているか |
|------|----------|----------------|
| 入口 | Webフォーム（このリポジトリの `index.html`） | GitHub Pages で公開。先生にURLを配る |
| 橋渡し | Google Apps Script | フォームの送信を受け取る |
| 保管庫 | Googleスプレッドシート | 回答が自動で追記される |

送信は `fetch(..., {mode:"no-cors"})` を使用しています。
これは Apps Script のクロスドメイン制約を回避するための作りなので、**触らないでください**。

---

## ファイル構成

```
summer-shift-toda/
├── index.html   ← フォーム本体（これだけで動く）
└── README.md    ← この説明書
```

`index.html` の中に、編集する可能性がある箇所が3つあります。

| 変数名 | 中身 | いつ変える |
|--------|------|-----------|
| `SLOTS` | 全コマの一覧。1行 = `["日付","時間","クラス","科目","講師名"]` | 担当表が変わったとき |
| `TEACHER_ORDER` | フォームに出す先生名と並び順 | 先生を増減するとき |
| `SCRIPT_URL` | 回答の送信先（Apps Script の `/exec` URL） | スプシを作り直したとき |

受け取ったHTMLを `index.html` に上書き保存して、下の手順で公開します。

## 公開（更新）の手順

`index.html` を新しくしたら、変更を GitHub に反映します。

Claude Code に、こう依頼すれば自動でやってくれます：

```
このフォルダの index.html を commit して push して。
GitHub Pages の既存公開URLを更新したい。
push前に、index.html 内に script.google.com/macros/ のURLが
入っているか確認し、無ければ作業を止めて報告して。
```

- 公開URLは**変わりません**（中身だけ更新されます）
- 反映には数分かかることがあります。古いページが出たら、少し待って再読み込み

> 手動でやる場合の Git コマンド（参考）:
> ```
> git -C "C:\Users\PebyCollege\summer-shift-toda" commit -am "update"
> git -C "C:\Users\PebyCollege\summer-shift-toda" push
> ```

## 公開前のテスト（毎回おすすめ）

1. 公開URLをスマホで開く
2. テストしたい先生名を選ぶ → 担当コマが正しく出るか
3. 適当に◯△✕を付けて送信 → スプシ「夏期講習シフト回答」に行が増えるか
4. 確認できたら、そのテスト行をスプシから削除

## つまずきポイント

- **送信がスプシに飛ばない** → `index.html` の `SCRIPT_URL` が古い／間違い。Apps Script の `/exec` URL を再確認
- **Apps Script のアクセス権** は必ず「全員」。これがないと先生がログインなしで送れない（スプシ自体は非公開のまま）
- **GitHub Pages は完全公開** … URLを知れば誰でも閲覧可（パスワード不可）。校舎名・先生名・日程が載る前提でOKなら問題なし
- **先生が増えたのに出てこない** → 公開（push）の反映待ち。数分おいて再読み込み
